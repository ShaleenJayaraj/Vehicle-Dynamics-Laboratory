# Vehicle-Dynamics-Laboratory
Vehicle Dynamics Laboratory is an engineering portfolio documenting my work in vehicle dynamics, motion control, embedded systems, digital twins, testing, and autonomous vehicle development. The goal is to bridge first-principles vehicle dynamics with production vehicle control systems through simulation, experimentation, and validation.
